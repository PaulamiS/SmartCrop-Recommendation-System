#  KrishiAI — Smart Crop Recommendation System

KrishiAI is an AI-powered crop recommendation web application designed to help farmers make smarter agricultural decisions using real-time weather and soil analysis.

The platform analyzes live temperature, humidity, rainfall, and soil conditions to recommend the most suitable crops for a particular location. It uses weather APIs, soil mapping logic, and machine learning-inspired prediction techniques to generate accurate crop suggestions for Indian farming regions.

## 🚀 Features

* 🌤 Real-time weather data using OpenWeatherMap API
* 🌱 Soil type & pH analysis
* 🤖 AI-based crop recommendation engine
* 📍 Location-based crop prediction
* 🌾 Multiple crop recommendations with confidence scores
* 🛒 Direct seed purchase links
* 📱 Fully responsive modern UI
* 🎨 Beautiful agriculture-inspired design

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript
* OpenWeatherMap API

##  Purpose

The goal of KrishiAI is to support farmers and agriculture enthusiasts by providing intelligent crop suggestions based on environmental conditions, helping improve productivity and decision-making.
